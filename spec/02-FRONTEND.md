# 02 — 前端规范（精美 + 功能完整）

> 目标：像一款成熟的学术产品，而不是 Demo。所有页面必须遵守本文件的设计令牌与组件规范；评审第一眼看到的是视觉，第二眼才是功能。

---

## 1. 设计令牌（写入 `design/tokens.css`，全站只用令牌，禁止散落魔法数字）

### 1.1 颜色

| ------------- | --------------------- | ----------------------- | -------- |
| `--bg`        | `#F7F8FB`             | `#0B1020`               | 页面背景     |
| `--surface`   | `#FFFFFF`             | `#121933`               | 卡片/面板    |
| `--surface-2` | `#F0F2F8`             | `#1A2244`               | 次级面板、输入框 |
| `--border`    | `#E3E7F0`             | `#27315A`               | 分割线      |
| `--ink`       | `#0F172A`             | `#E8ECF8`               | 主文字      |
| `--ink-2`     | `#475569`             | `#9AA6C8`               | 次文字      |

| `--danger`    | `#EF4444`             | `#F87171`               | 错误       |

图谱角色色：基石 `--primary`、中间 `--ink-2`、边缘 `--accent`。

### 1.2 字体与排版

- 界面：`Inter` + `Noto Sans SC`；阅读/译文区：`Noto Serif SC` + `Source Serif 4`；代码与公式：`JetBrains Mono`。
- 字号阶梯：12 / 13 / 14 / 16 / 20 / 24 / 32；正文行高 1.6，标题行高 1.3。
- 阅读区正文最大宽度 72ch。

### 1.3 间距、圆角、阴影、动效

- 间距基数 4px，常用 8 / 12 / 16 / 24 / 32。
- 圆角：控件 8px，卡片 12px，弹窗 16px。
- 阴影三档：`sm`（卡片）、`md`（悬浮面板）、`lg`（弹窗）；深色主题以边框替代大阴影。
- 动效：过渡 150–250ms `ease-out`；页面切换淡入+8px 位移；列表项依次入场（stagger 30ms，≤ 10 项）；遵守 `prefers-reduced-motion`。

## 2. 通用组件（`design/components/`，先于页面完成）

Button（主/次/幽灵/危险，含加载态）、IconButton、Input、Select、Tabs、Dialog、Drawer、Tooltip、Popover、Toast、Badge、Tag、Progress、Stepper、Skeleton、EmptyState、ErrorState、DataTable、Card、SplitPane（可拖拽分栏）、CommandPalette（⌘K）、ThemeToggle、AnchorChip（引用小标签）、JobCenter（任务中心）。

规则：

- 图标统一 lucide-react，线宽 1.75，尺寸 16/20。
- 所有可点击元素有 hover、focus-visible、active、disabled 四态；焦点环可见。
- 每个异步区域必须有三态：**加载（骨架屏）/ 空（插画感文案 + 行动按钮）/ 错误（原因 + 重试）**。

## 3. 应用外壳

- 左侧窄导航栏（图标 + 文字，可折叠）：资料库、阅读、问答、发现、图谱、写作。
- 顶栏：全局搜索（⌘K 命令面板：跳转页面、搜索文献、触发常用操作）、任务中心入口（显示进行中任务数）、主题切换、当前用户切换（多用户推荐用）。
- 右侧 **Agent 抽屉**：任意页面可呼出（快捷键 `⌘J`），带当前页面上下文（当前文献/选区）发起问答。
- 路由：`/library`、`/reader/:docId`、`/qa`、`/discover`、`/graph/:graphId?`、`/writing`。
- 浅色/深色双主题，跟随系统并可手动切换，切换无闪烁。
- 桌面优先：≥1280px 完整布局；1024–1279px 自动收起次要面板；不做手机端适配，但不得出现横向滚动条。

## 4. 页面规格

### 4.1 资料库 `/library`

布局：顶部操作条（上传、批量上传、搜索、标签筛选、卡片/表格视图切换）+ 主体列表。

- **上传区**：整页可拖拽；支持多文件；每个文件一行进度，用 Stepper 展示 `上传 → 解析 → OCR → 索引 → 完成`（来自 SSE 的 `stage`）；扫描件显示"OCR 中 x/y 页"；长书显示窗口级进度。
- **文献卡片**：标题、作者、年份、版本徽标（v1/v7）、来源类型徽标（矢量/扫描）、页数、解析状态、标签；hover 显示快捷操作（打开/问答/删除/加入图谱）。
- **表格视图**：可排序列，多选后批量删除/打标签/建图谱。
- **去重弹窗**（关键体验）：左右并排对比"库中已有"与"新上传"，显示相似度、版本号、页数、解析来源；差异章节高亮；顶部给出建议文案（例如"库中已有版本较新，建议保留"）；底部按钮：`保留现有`、`覆盖`、`两者都保留`、`查看修订摘要`；修订摘要以可折叠面板展示，数字来自 diff 统计。
- 删除需二次确认；空状态引导"拖拽 PDF 到此处，或直接用标题搜索下载"。

### 4.2 阅读台 `/reader/:docId`（最核心页面）

三栏可拖拽布局：

- **左栏**：标签页 `目录 | 缩略图`。目录为可折叠标题树，随滚动高亮当前章节；点击平滑跳转。
- **中栏**：PDF 渲染（pdf.js，含文本层，可选择复制）；工具条：缩放、适应宽度、页码跳转、搜索、主题；虚拟化渲染，仅渲染可视页 ± 2。
  - 正文中的引用标记（如 `[11]`）悬停显示参考文献卡片（标题、作者、年份、含金量、"入库"按钮），点击跳到参考文献条目；参考文献条目旁有"返回引用处"按钮（双向跳转）。
  - 锚点高亮：从问答/综述点击锚点进入时，自动滚动到页并用 `--hl` 高亮 bbox，3 秒后淡出但保留可再次定位。
  - 划词出现浮动工具条：`翻译 | 提问 | 复制 | 高亮`。
- **右栏**标签页：
  1. `结构`：元信息卡（标题、作者+机构、摘要）、表格列表、图表列表、公式列表、参考文献列表、附录；每项可点击跳转到原文位置，表格以 HTML 渲染并可切换"原图"，公式以 KaTeX 渲染并可复制 LaTeX。
  2. `问答`：针对当前文献的聊天（同 4.3 组件）。
  3. `翻译`：整篇翻译状态与下载（Markdown/HTML）。
- **中英对照模式**：工具条一键切换，中栏分为左右两栏（原文 | 译文），按 block 对齐，**拖动任一侧另一侧自动联动**；译文区可独立调整字号；代码与公式保留英文。
- 长书（541 页）：目录支持搜索过滤；打开不得卡顿（首屏 ≤ 2s）。

### 4.3 问答 `/qa`

- 顶部**范围选择器**：单篇 / 选集（多选文献）/ 全库；模式切换：`问答 | 对比`。
- 对话区：流式输出，打字机效果；每个论断后出现 **AnchorChip**（如 `[1]`），hover 弹出原文片段（文献名、页码、片段文字），点击在右侧分屏打开 PDF 并高亮。
- 拒答态：专门的样式（灰色卡片 + "未在所选文献中找到依据" + 建议："扩大范围 / 换个问法"）。
- 对比模式：输出表格，行=对比维度、列=论文，每个单元格带 AnchorChip；支持导出 Markdown。
- 预设问题芯片（如"这篇论文的训练硬件是什么？""作者与机构""超参数设置"），一键填入。
- 历史会话列表（左侧）。

### 4.4 发现 `/discover`

- 三个标签页：`推荐流 | 搜索下载 | 参考文献导入`。
- **推荐流**：卡片含标题、作者、日期、摘要折叠、**推荐理由标签**、GitHub 徽标（⭐ 数）、👍/👎（lucide 图标）与"入库"按钮；反馈后卡片有轻量动画且列表重排；右上"追踪设置"抽屉（类别、关键词、频率、立即刷新）；顶部切换当前用户以展示多用户差异。
- **搜索下载**：输入标题/关键词，结果列表，点击"入库"后进度进入任务中心。
- **参考文献导入**：选择一篇文献后展示其参考文献表：序号、标题、年份、**含金量分数条 + 理由气泡**、状态（未入库/已入库/下载中/失败）；顶部滑块设置最低含金量，被剔除项折叠显示"已过滤 n 条应付式引用"；一键"导入所选"。

### 4.5 图谱 `/graph/:graphId?`

- 创建流程：选择 N 篇文献 → 生成图谱（进度）。
- 主画布（Cytoscape）：节点大小=PageRank；颜色按角色（基石/中间/边缘）；边带箭头；布局可切换"力导向 / 时间轴（x 轴为年份）"；缩放、平移、框选；hover 高亮邻居并淡化其余；点击节点右侧出详情（标题、年份、入度/出度/PageRank/介数、角色、打开阅读）。
- 左侧筛选：按角色、年份范围、最小入度。
- 右侧标签页：`综述 | Future Work | 指标榜`。
  - 综述：流式渲染，论断带 AnchorChip。
  - Future Work：卡片列表，状态徽标（`仍开放` 绿 / `部分解决` 琥珀 / `已被解决` 灰 / `未知` 虚线），展开看证据（论文 + 锚点）；"已被解决"默认折叠。
  - 指标榜：基石 Top 5 与边缘论文列表。
- 图例固定显示；导出 PNG/JSON。

### 4.6 写作工坊 `/writing`

三个子工作区（顶部 Tab）：

1. **论文框架**：左侧输入 idea（多行）与"生成"；中间 Markdown + KaTeX 编辑器，章节：Abstract / Introduction / Related Work / References；右侧**参考文献校验面板**：每条显示 ✔ 已验证（点击打开来源）/ ⚠ 未验证 / `[待补充]`，一键导出 BibTeX；正文中的引用键点击可定位。
2. **图表工坊（Figure Lab）**：左侧描述需求 + 选类型（Mermaid / Graphviz / TikZ / Matplotlib）；中间 Monaco 脚本编辑器；右侧实时渲染预览；运行报错时显示可读错误与"让 Agent 修复"按钮；可导出 SVG/PNG/脚本。
3. **数据工坊（Data Lab）**：上传 CSV → 数据预览表 → 选择图表类型（表格/折线/柱状/雷达/三维雷达）与 X/Y 列 → ECharts 渲染 → 下方显示**自动生成的 Figure Caption**（可编辑、可复制）与"统计依据"折叠面板（展示 `stats`）；导出 PNG。
4. 另有**学术翻译**侧栏：左中文、右英文，一键翻译，可复制。

## 5. 体验细则（验收时逐条检查）

- 首屏加载 ≤ 2s；列表 > 100 项使用虚拟化；PDF 仅渲染可视页。
- 所有操作 100ms 内有视觉反馈；> 400ms 的显示加载态；长任务进入任务中心并可跳转。
- 快捷键：`⌘K` 命令面板、`⌘J` Agent 抽屉、`/` 聚焦搜索、`Esc` 关闭弹层、阅读台 `←/→` 翻页。
- 表单与按钮的禁用态、校验提示完整；错误提示用人话，包含下一步建议。
- 布局无抖动（图片/PDF 页预留尺寸）；文本溢出统一省略并带 Tooltip。
- 无障碍：对比度 ≥ 4.5:1；所有图标按钮有 `aria-label`；键盘可完成主要流程。
- 视觉一致性检查：同类元素同一间距/圆角/字号；不允许出现未设计的默认控件。

## 6. 前端禁止项

- 禁止使用组件库的默认主题而不套用令牌；禁止行内魔法色值。
- 禁止出现控制台警告、`any` 类型滥用、未处理的 Promise。
- 禁止页面间风格不一致（例如某页没有空态/错误态）。
- 禁止把后端返回的原始错误对象直接展示给用户。
