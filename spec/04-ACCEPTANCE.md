## 2. 硬性用例

### 用例 A：去重与版本演进（对应官方 3.1）
1. 上传 `1706.03762v7.pdf` → 入库成功。
2. 再上传 `1706.03762v1.pdf` → **必须**弹出去重预警，判定为 `same_paper_other_version`，并明确提示"库中已有版本较新，建议保留"。
3. 弹窗必须支持 `保留现有 / 覆盖 / 两者都保留`。
4. 点击"查看修订摘要"，显示章节级差异统计和不超过 200 字的摘要，摘要内数字与统计一致。
5. 将文件改名后重新上传，结果必须相同（证明不依赖文件名）。

### 用例 B：多模态与长文档解析（对应官方 3.2）
- **B1 矢量版** `v1.pdf`：标题、作者及机构、摘要、标题树、表格（HTML）、公式（LaTeX）、图表、参考文献、附录均可在"结构"面板查看并点击跳转原文。
- **B2 扫描版** `v1_img.pdf`：OCR 后能还原标题、摘要、章节、图表与参考文献；对其做去重时提示"内容相同、格式不同"，允许两者都保留。
- **B3 长书** 541 页：完整入库；进度条按窗口推进；已完成窗口可提前检索；解析内存峰值 ≤ 4GB；阅读台打开与翻页流畅。

## 3. 问答验收

### 3.1 单篇（以 Attention Is All You Need 为例）
下列问题需基于原文回答并带锚点。**期望答案必须由人工对照原文核对后写入 `golden_qa.json`**；下表"待核对要点"仅供出题方向，不得直接当作答案硬编码。

| 问题类型 | 示例问题 | 待核对要点 |
|---|---|---|
| 作者与机构 | 列出所有作者及其所属机构 | 与首页一致 |
| 超参数 | 优化器 β₁、β₂、ε 设置是多少？ | 在训练/优化器小节 |
| 硬件 | 训练使用了多少块什么型号的 GPU？ | 在训练小节 |
| 结果比对 | 英德、英法翻译任务上 Transformer 的 BLEU 分数？ | 在结果表格；注意 v1 与 v7 数值可能不同 |
| 引用信息 | 参考文献 [11] 的完整引用信息？ | 与参考文献条目一致 |

### 3.2 跨文对比
| 对比 | 需要覆盖的维度 |
|---|---|
| BERT vs Transformer Encoder | 沿用了什么、舍弃了什么（如双向、预训练目标、位置编码、解码器等），每条带出处 |
| GPT-1 / GPT-2 / GPT-3 | 参数量演化、层归一化位置调整、上下文窗口递增 |

> 如库中缺少某篇论文，系统必须明确提示"未入库，无法对比"，不得凭模型记忆作答。

### 3.3 抗幻觉
- 提问文献中不存在的内容（如"这篇论文在 ImageNet 上的准确率是多少？"）→ **必须拒答**。
- 让 Agent 给出不存在的论文参考文献 → **不得编造**，应返回未找到/未验证。
- 回答中的任意数字，点开锚点都能在原文找到。

### 3.4 指标（初始目标）
- 单篇黄金集：要点命中率 ≥ 85%，锚点页码正确率 ≥ 90%。
- 跨文黄金集：维度覆盖 ≥ 80%，单元格均带出处。
- 无依据问题拒答率 100%。

## 4. 阅读与翻译验收
- 抽检 10 个正文引用标记 `[n]`：跳转到的参考文献条目全部正确，且可返回引用处。
- 划词翻译首字延迟 ≤ 1.5s；译文中代码与公式保持英文。
- 全文翻译可下载 Markdown/HTML；译文公式 LaTeX 与原文逐条一致。
- 对照模式：拖动任一侧，另一侧对应段落在视口内（误差 ≤ 1 个 block），无来回抖动。

## 5. 发现与推荐验收
- 输入论文标题 → 自动下载入库并解析成功。
- 对 Transformer 的参考文献列表批量导入：每条有含金量与理由；滑块调高阈值后应付式引用被折叠并可查看原因。
- arXiv 追踪可手动触发与定时触发；重复运行不产生重复条目。
- 推荐项均带理由；有 GitHub 的论文排序靠前并显示 stars；点踩后同类得分下降；两个用户的推荐不同。

## 6. 图谱与综述验收
- 选 20 篇相关论文 → 生成引用图谱；基石节点与边缘节点有明确标识并可解释（显示指标）。
- 综述每条论断可点击溯源。
- Future Work：已被后续论文解决的条目标为 `solved` 且附证据；证据不足的为 `unknown`，不得展示为"值得探索"。

## 7. 写作与可视化验收
- 输入一个 idea → 论文框架；References 中 100% 为 `verified`，点击可打开来源；BibTeX 仅含已验证条目。
- 四类图（Mermaid/Graphviz/TikZ/Matplotlib）各生成一个；脚本报错可自动修复或给出清晰报错；TikZ 无环境时有降级提示。
- CSV → 表格/折线/柱状/雷达/三维雷达；Figure Caption 中每个数字都能在统计依据里找到。
- 中文摘要 → 英文学术摘要；公式与术语保持正确。

## 8. 非功能验收

## 9. 端到端演示脚本（评审现场，必须一条命令可回放）

1. 上传 v7，再上传 v1 → 去重弹窗 → 保留 v7 → 查看修订摘要。
2. 打开 v7：标题树、公式、表格；点击 `[11]` 跳转并返回。
3. 提问"训练用了什么 GPU？" → 带锚点回答 → 点击高亮原文；再问一个文献里没有的问题 → 拒答。
4. 开启中英对照阅读，拖动联动。
5. 在发现页：按标题搜索并入库 BERT、GPT 系列；对 Transformer 参考文献批量导入并看含金量。
6. 跨文对比：GPT-1/2/3 参数量与上下文窗口。
7. 选 20 篇建图谱 → 基石节点 → 生成综述 → Future Work（含已解决标记）。
8. 写作工坊：输入 idea 生成框架与已验证参考文献 → 生成架构图 → 上传 CSV 出图并生成 Caption → 中译英摘要。
